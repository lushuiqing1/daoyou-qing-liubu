# 道友请留步 · 网页战斗轻体验

浏览器直接进入竹林连续五战，可在起始、御剑、守阵、灵术四组搭配之间重试。复用 Godot 1.5.0 的战斗规则与独立水墨素材；固定角色为炼气六层，桃木剑、粗布衣、古玉佩，配青冥剑和灵气丹，适合快速体验。

纯 HTML、CSS、JavaScript，无需安装引擎或构建依赖。双击 `index.html` 可在现代浏览器打开；也可把整个目录作为静态网站发布。所有运行资源均在本目录，无远程字体、图片或第三方脚本。

- 点击两枚相邻棋子或拖动交换；三枚同色消除，直线四枚及以上返步。
- 点选三式后确认施放；灵墨足够可重复使用，不扣交换步。
- 回合按主动操作推进，等待时不会受攻击；第五战胜利后展示实际复盘。
- 每次成功事务后自动保存独立试玩进度，刷新可继续；本地保存受限时仍可游玩。
- 设置支持减少动态效果、可选短音效与重看提示。键盘操作见页面「规则」。

体验仅包含竹林战斗；铜钱只记录在本局，不导入或修改原生游戏及旧网页存档。完整游戏的四境、养成、收藏和六项试炼见 [Godot 1.5.0 下载页](https://github.com/lushuiqing1/daoyou-qing-liubu/releases/tag/godot-v1.5.0)。

运行规则验证：`node --test tests/engine.test.cjs`。接口与固定种子重放见 [ENGINE.md](ENGINE.md)，素材来源见 [ASSETS.md](ASSETS.md)。
