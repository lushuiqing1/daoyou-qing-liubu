# 道友请留步 · Godot 水墨原生版

当前为 **1.5.0 通关试炼版**：每关五只怪连续登场，第五只为最强 Boss。原生 GDScript / Control / Tween，不嵌入网页。

## 六项通关试炼

普通四境通关后，从历练页进入六项试炼。每项只打指定章节的连续五战，首领击败后直接判定条件。统一使用桃木剑、粗布衣、古玉佩，满血、无倾向；不读取实际角色成长，固定三式/法宝，禁用消耗品、购物、突破和换装。重试恢复相同种子与角色配置。

| 试炼 | 章节与境界 | 获章条件 |
| --- | --- | --- |
| 御剑初试 | 竹林道／炼气六层 | 通关，强化剑气至少2次 |
| 守阵破浪 | 古驿迷雾／炼气六层 | 通关，实际破盾返墨至少3次 |
| 灵术回环 | 枫火坡／炼气七层 | 通关，聚灵紫消至少3次 |
| 破雾斩甲 | 古驿迷雾／炼气六层 | 通关，实际移除敌盾至少36点 |
| 连消归元 | 沉月潭／炼气九层 | 通关，至少一次三层连锁 |
| 留步速决 | 竹林道／炼气六层 | 不超过32次有效交换通关 |

获章只写入对应印章与最佳交换记录，不增加普通铜钱、收藏、胜场或通关次数。条件未达成也可看完整复盘和重试。试炼独立保存到trial-v1.json及备份；暂停后从试炼入口继续，普通历练进行中不能开始或继续试炼。结果先保存再记章，异常退出后可补记且不会重复奖励。

六份合法获章操作在tests/trial_replays，重放方法见docs/TRIAL-REPLAYS.md。完整配置与三批规格见docs/CONTENT-ROADMAP.md。

## 修炼分支更新

修炼页增加可选的御剑、守阵、灵术倾向，炼气三层/六层/九层分别开启一/二/三阶。御剑每枚赤刃额外1/2/3点伤害，再算连锁；守阵每个玩家回合开始额外2/4/6盾；灵术每关初始墨额外1/2/3点，上限7。可免费更换或取消，没有倾向时沿用原打法。

倾向整轮锁定，关间突破后提升的阶数从下一关生效。战斗详情按章节快照说明实际来源，旧规则2/3历练不增加倾向效果，新历练使用规则4。

## 策略流派更新

二十只怪采用各自的行动序列，保留当前气血、基础攻击、奖励和击败回复。重击始终先蓄力预告，首领激怒不会改动已锁定伤害。顶部关卡进度可查看下一怪特点和首次行动，方便规划接战资源。

剑气诀获得四连后强化，金刚符获得护盾被击破返墨，聚灵阵强化下一次紫消。增益不叠加，同回合接战延续，结束回合及新关卡清除。藏经阁提供起始、御剑、守阵、灵术四组推荐，集齐后可在没有进行中的历练时一键装备；仍可自由混搭。

新增可跳过和重看的事件教学、事务内实际战斗统计、简短结算与详情、最近一局记录。旧正在进行的历练按旧规则打完整轮，详细统计标注开始记录的位置，新历练才启用新增联动。完整三批规格见docs/CONTENT-ROADMAP.md；三个版本各有独立Windows和源码ZIP，当前源码继承全部三批内容。

## 打开与游玩

- 仓库源码：用 Godot 4.7.2 导入本目录的 `project.godot`，等待资源导入后按 F5 运行。
- Windows 源码脚本：将 Godot 可执行文件路径作为第一个参数传入 `启动游戏.cmd` 或 `打开工程.cmd`。换电脑时优先使用 Godot 项目管理器导入。
- 离线试玩目录：`道友请留步-Godot-Windows-通关试炼版-1.5.0-20261003`，双击 `启动游戏.cmd`，无需安装引擎。
- 换电脑开发时导入 `project.godot`；推荐已验证的 Godot 4.7.2。

## 界面基础

按钮使用独立无字SVG笔触与原生九宫格样式：朱砂主操作、宣纸墨线次操作、青墨辅助操作、暖纸朱印选中态。悬停加深墨色，按下加深刷痕，不可用显示灰纸墨线，键盘焦点使用透明朱砂角线。导航选中项改为墨晕和毛笔下划线，设置开关沿用原生CheckButton并换用水墨图标。文字、命中范围、业务数据与事件保持原生。

本版沿用1.2.2按钮素材与1.2.1战斗反馈机制，新增内容由原生控件和实时状态接入。按钮素材来源见assets/sources/INK-BUTTONS.md。

洞府、关卡、藏经阁、行囊、修炼、行商、任务和记录全部使用一致的纸面标题、信息卡、选中态、底部导航和操作按钮。更多、设置、物品及术式详情、重开与清除确认窗口一起精修。保留原生控件、动态数据和现有独立插画。

战斗增强剑气、命中闪红与后退、描边伤害数字、即时血条变化。击败后先退场，再按事件顺序展示下一战提示、血条与怪物入场；连锁同时击败多只时不会跳过中间怪物。第五只首领使用独立插画与红色登场提示。格挡、治疗、护盾、蓄力和震怒有各自的反馈。设置可关闭原创短音效，或减少动态效果，保留静态命中、血条及接战提示。战斗原有静态布局保持一致。

战斗中角色、怪物不显示名字；双方状态不使用方框。红心旁显示随实际气血变化的细血条，不显示血量数字或百分比。
剑表示基础攻击，蓝盾表示实时护盾；数值和敌方行动预告保留。点击人物或状态区域仍可查看完整详情，状态弹窗统一称为我方／敌方状态。
棋盘方块去掉右下角的文字，只保留五色图案；点击、拖动、提示和键盘操作沿用。
保留水墨背景、独立人物、术式卡和操作区，基础数值与奖励沿用。旧历练按开始时的规则续玩，新进度使用版本化保存。

## 五战规则

洞府 → 三式装备 → 关卡列表 → 连续五战 → Boss 奖励 → 关间整备 → 下一关 → 四关通关。

- 四关各五只怪，共20只。前四只逐只增强，第五只气血和攻击最高，并在半血时激怒。普通怪复用本关普通插画，Boss 使用独立首领插画。
- 普通怪击败后直接接战，没有路线、行商节点、奇遇或逐只选牌窗口。保留棋盘、三式实例、灵墨、护盾、剩余步数、连击增益和本回合返步额度，剩余连锁继续结算。
- 6×6 棋盘，五色攻击／恢复／护盾／铜钱／灵墨。无效交换不扣步，下落补充、每层15%连锁收益、无解重排。
- 直线四枚及以上消除返还1步，每个玩家回合最多返还2步；新怪进场不补满步数。每击败一只恢复10%最大气血。
- 三张不同常驻术式整轮锁定，灵墨足够可反复施放。选择后确认，同一术式在接战后仍保持选择。
- Boss 固定解锁对应术式，已拥有时转为20铜钱；另可择一卷未收藏术式。全部收藏后追加20铜钱，新术式下轮可装备。
- 领取 Boss 奖励后可修炼、购物、使用物品、查看本轮详情，再开始下一关。气血和法宝延续，新关卡重新布置棋盘。
- 四关分别侧重蓄力预判、护盾破甲、连续攻击、沉潭守阵。蓄力预告后激怒，不改变已锁定重击伤害。
- 保留11种术式、9件法宝、10种物品、10层境界、装备、行囊、任务、记录和设置。

| 关卡 | 首怪／Boss 气血 | 首怪／Boss 普攻 | 固定术式 |

| 竹林道 | 99／231 | 14／22 | 破甲符 |
| 古驿迷雾 | 162／378 | 20／31 | 聚灵阵 |
| 枫火坡 | 252／588 | 28／43 | 焚风诀 |

点击关卡卡片可查看五只怪的数值。战斗显示第几只／5、双方气血及敌方行动；点击人物查看完整状态。
操作：点击相邻灵玉或拖动交换，1–3选择术式，Enter施放，E结束回合，H提示，Esc关闭详情或暂停。

## 进度与历史版本

不读取网页旧存档。新版原生进度保存至 `DaoyouGodotInk` 的 `progress-v2.json` 和备份，源码和试玩包共用此独立存储。新版主档和备份均不存在时，首次从原生 `progress-v1.json` 及备份只读迁移，原文件保留给历史版本使用。新版双损坏时显示恢复错误并阻止自动写入，不从旧文件反复导入。
已有原生1.0.0进度可衔接到五战流程，保留角色、货币、物品、收藏、成长及记录；旧正在交战的敌人按剩余气血比例换算为新配置，待领取奖励仍可领取。
验证全部使用 `-- --no-save` 或专用测试文件，没有清除用户进度。原网页、1.0.0 Windows目录和历史 ZIP 保留。
